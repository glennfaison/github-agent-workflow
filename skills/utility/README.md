# Utility

Building blocks the workflow skills call. Each is useful on its own and knows nothing about GitHub plumbing: none claims an item, sets a label or posts a comment.

- **[unattended-triage](./unattended-triage/SKILL.md)**: Decide an issue's category and state and write the outcome comment (Agent Brief, ready-for-human note or Triage Notes). Adapted from `triage` in mattpocock/skills.
- **[unattended-grilling](./unattended-grilling/SKILL.md)**: Work out every open decision and ask the whole ready frontier in one round, each question with a recommended answer. Adapted from `grilling` in mattpocock/skills.
- **[merge-safety](./merge-safety/SKILL.md)**: Assess whether a PR is safe for an agent to merge on its own.
